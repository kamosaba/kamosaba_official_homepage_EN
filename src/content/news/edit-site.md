# A Tale of Major Website Overhaul

Hello! Thank you for always visiting the Kamosaba official homepage!
This time, I've **significantly overhauled** the website, so I'll summarize the changes and some behind-the-scenes stories in a blog style.

---

## Screenshot Backgrounds from the Current Server

First, the biggest change.  
For the top page background, I used **screenshots of the current server**.

Since the server has developed quite a bit, I thought, "I have to show this," and adopted it for the background.  
What's more, it's not just one image; it displays **multiple images in a slideshow format**.

- Automatic sliding feature  
- Manual switching possible by clicking  
- Uses photos from near the initial spawn point  

I plan to **continuously add more** to this slideshow as we get more photos.  
I hope it becomes something like a growth record of the server.

---

## Fading the Borders Between Images and Solid Backgrounds

I also adjusted fine details of the appearance.  
I changed the design to **blur the borders** between images and solid backgrounds.

This makes the overall connection of the screen feel more natural,  
and as a result, it looks **a bit more stylish**.

It's a subtle change, but it's the kind of "easy on the eyes" and "good atmosphere" modification.

---

## We Made a Documentation Page!

I've also created a new **Documentation page**.

It's still under preparation,  
but I plan to **publish content sequentially** as soon as it's ready.

However, since images aren't ready yet,  
detailed explanations and supplementary info might **primarily be guided through Discord** for now.

In the future, I want to make it so everything is completed solely on the documentation page.

---

## In Conclusion

In this overhaul, I worked with these three things in mind:

- Visual impact  
- Readability  
- Future scalability  

The website is still a work in progress,  
but I'd be happy if you could enjoy seeing it grow bit by bit.  
Stay tuned for future updates!
