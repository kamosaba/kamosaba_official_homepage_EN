## 🛠 This Update's Content

### 1. Introduction of a "Proxy"
This is the single biggest change! We've completely revamped the server's entrance.
This makes it possible, for example, to create separate servers specifically for events.
From now on, things like "The main server is shared by Java and BE, but let's gather at that other server just for the event!" can be done smoothly!

### 2. Powered Up Management! "AdvancedBAN"
We've introduced a system called "AdvancedBAN" that allows for more detailed and robust management.
This is an update to protect the environment where everyone can play "Fun & Relaxed" more reliably than ever before.

### 3. System Reconstruction & Database Migration
We cleaned up and reconstructed the server's internals.
Furthermore, we optimized how logs (records) are stored—think of it as changing from "paper notebooks" to a "high-tech digital database"—so the server's operation should be smoother than ever!

### 4. Maintenance Mode & MOTD (Message of the Day) Updates
We implemented a feature to clearly display "Currently under maintenance!" during work.
Also, the content displayed in the multiplayer server list (MOTD) has been updated. Be sure to check it out!
