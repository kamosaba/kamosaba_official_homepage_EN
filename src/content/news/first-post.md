### What is Kamosaba?
Kamosaba is an open Minecraft server that you can join from both Java and Bedrock editions.
With the motto "Fun & Relaxed," we aim to be a community where anyone can feel free to join.

The main base of activities is **Discord**. When you join the server, please be sure to join our Discord as well!

We have many events planned for the future, so stay tuned!
