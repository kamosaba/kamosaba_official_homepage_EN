# 🎮 Java Edition Join Guide

Explaining the steps to join "Kamosaba" in a step-by-step format that's easy for beginners to understand. ✨

### 📝 What You Need
* **Minecraft: Java Edition**（PC version）
* Internet connection

### 🚀 Steps to Join

1. **Launch Minecraft**
   Launch Java Edition from the launcher and bring up the main menu.

2. **Select "Multiplayer"**
   Click the "Multiplayer" button on the menu screen.

3. **Click "Add Server"**
   Press the "Add Server" button at the bottom right of the screen.

4. **Enter Server Information**
   Copy and paste the following information into the input fields.
   * **Server Name**: Kamosaba (Any name that's easy for you to recognize is fine)
   * **Server Address**: Enter one of the following:
     1. `play.kamosaba.net`
     2. `かもさば.net`

5. **Press "Done" and Connect**
   Once you've finished entering, press "Done," double-click "Kamosaba" added to your server list (or select it and click "Join Server"), and your adventure begins! 🦆

### 💡 If You Can't Connect
* **Typos in the Address**: Check if there are any extra spaces.
* **Version**: Ensure you are running the latest version that the server supports.
